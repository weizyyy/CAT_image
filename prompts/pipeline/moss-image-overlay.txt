【模式：MOSS-Image · Layout JSON + 二维 Galgame 事件 CG】

一张图取同一幕里的一个瞬间。**人物标签定结构，英文 caption 写光影与关系，Layout 框定位置。** 横幅里优先给表情、目光和动作留画幅，再用场所线索交代背景。

## 提示词结构（三层分工）

    ① 全局画面（summary.caption）—— 画风 → 景别 / 机位 → 人物位置与相互关系 → 地点 / 光影
    ② 局部形象（items[].tags / caption）—— 英文短标签定可见外貌与服饰，英文句子写动作与局部光影
    ③ 元素位置（items[].bbox）—— 用画布中心为原点的绝对像素，按 [上,左,下,右] 定位可见元素

| 内容 | 用什么写 |
|---|---|
| 二维视觉小说事件 CG、共同的画面语言 | `summary.caption`；`summary.meta` 可用 `anime illustration`、`visual novel event CG` |
| 脸型 / 瞳色 / 发型 / 年龄 / 可见体型 / 衣着 | 对应 `character` 的 `tags`，一项一个特征短语 |
| 表情 / 目光 / 朝向 / 手与物的接触 | 对应人物的 `caption`；两人互动的前后关系也在全局写清 |
| 关键道具 / 辨识地点的建筑或陈设 | 独立的 `object` 项；其他环境与光线留在全局句 |
| 画内确实可读的招牌或标记 | `text` 项，原文与排版描述分开 |

## 书写规则

1. **人物标签**按年龄与身份特征 → 五官与发型 → 入镜体型 → 衣饰材质 → 姿态排列。优先准确的 Danbooru 常用词，细节用同风格英文短语补足。简短、具体，一项一义，不写分类前缀、权重或无关质量词。
2. **固定特征逐项照用**，例如 `low nose bridge` 不换成 `straight nose bridge`，可见的疤痕或痣要保留位置。年龄照本轮明确给出的数字或文字写，气色、汗水、红晕取本轮可见状态。按景别写体型：胸像保留肩颈和脸，腰部以上不写鞋袜，全景才交代完整轮廓。多人各写一套，不把 A 的衣物或发色混入 B 的框。
3. **自然语言写可见关系**。写清谁朝谁、哪只手托住哪里，手掌与物件如何接触、谁遮挡谁。局部 `caption` 补全动作，避免逐项复述 `tags`。取景、视点和主光方向以 `summary.caption` 统一。
4. **二维画风**。用有轻重的清楚轮廓、平整色面、成组的赛璐璐阴影及局部柔和渐变。眼睛用清楚的虹膜分区和少量高光表达眼神。皮肤保留原有肤色和五官，用柔和的明暗面过渡；布料用成组褶线、材质轮廓和受光表现细节。背景细节与对比低于脸和手势。整幅按同一媒介描绘。

## 场景与构图约束

- **优先按本轮占位符定景别与视点。** 近景和中景让脸与主要动作占足画幅。只有动作范围或场景本身需要时才拉远；用一两处入镜标志交代剩余空间。
- **侧倾是可选构图手法。** 正面、侧身、前倾或镜头滚转按动作选。侧倾时写清头、肩、躯干或伸手方向，人物框仍为轴对齐矩形。若用镜头滚转，背景透视与重力方向按同一视点表达。不固定沿画面对角线摆放人物。
- 单幅事件插画。对白与心理活动化为可见表情或动作，不画对白框、字幕、分镜边框或水印。只使用本轮可见场景和要点。

## 自检

1. 是否一幅图一个 Layout 对象，字段与中心像素坐标都合法？
2. 主角的神态、手势和叙事动作是否得到足够画幅？有无为了交代服饰或背景而拉远镜头？
3. 年龄、五官、固定特征和衣饰是否在同一人框内？有没有写到裁出画外或被遮住的细节？
4. 目光和接触点是否自洽？有侧倾时，方向是由这一幕决定的吗？
5. 全图的线条、色面与阴影是否统一为二维插画？画内文字是否逐字保留？
