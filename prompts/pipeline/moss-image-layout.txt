【MOSS-Image · Layout JSON 输出协议】

图像提示词按本协议和所选模式的三层分工组织。通用的景别裁剪、主体分配与事实约束仍适用，纯文本词序不用于 Layout JSON。

## 字段与坐标
- 一个占位符对应一幅单画面。顶层字段只有 `summary`、`items`、`bbox_coord_space`、`bbox_format`。
- `summary` 必有英文 `caption`，`canvas` 写 `"single"`。`meta` 和 `palette` 是可选的字符串数组，按当前模式使用。
- `items` 是非空平铺数组。每项必有 `label`、`caption`、`bbox`；`label` 只能是 `"character"`、`"object"` 或 `"text"`。`caption` 用英文描述，事实按共用事实规则随对象写入。可用 `tags` 或 `palette` 字符串数组补充局部特征。`text` 项必须另有 `text` 字段。
- `bbox_coord_space` 写 `"abs_centralized"`，`bbox_format` 写 `"yxyx"`。原点在画布中心，x 向右为正、y 向下为正。框是 `[y_min,x_min,y_max,x_max]`，即 `[上,左,下,右]`，四项均为整数。上 < 下、左 < 右，四条边不能越出本轮【布局画布】的范围。
- 以本轮给出的实际像素宽高为准。例如 1536×864 的 x 范围是 −768～768，y 范围是 −432～432。换画布时重算框，不照抄示例坐标。JSON 内不加宽高、比例、旋转角度或自定义字段。

## 框选与输出
1. 一个入镜人物用一个轴对齐框，包住他在画面中的可见轮廓。裁出画面的部位留在框外。手势、头与躯干的角度写在 caption 中，不拆成手、眼睛或衣服的单独框。
2. 只框需要定位的人物、道具和显眼环境标志。其他背景用 `summary.caption` 交代。按背景到前景排列条目。遮挡、接触和文字落在实物上时允许框重叠，caption 交代哪个东西在前、哪个在后。
3. 只有实际入镜且原文明确的文字才建 `text` 项。其 caption 写承载表面、字形和位置，`text` 原样保留字符、标点、大小写和换行，按 JSON 规则转义引号与换行。普通对白不作屏幕字幕。
4. `---IMAGES---` 段每条占位符只写一个紧凑 JSON 对象，单独占一行，不加围栏、编号、解释或对象外的提示词。其他输出段沿用原协议。
