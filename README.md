# CAT_image 2.1.1

SillyTavern 1.18+ 和 Tauritavern 的第三方文生图扩展。主模型在回复中放置 `[img:…]`，扩展在回复完成后逐个分析占位符，并在原位显示图卡。

## 设置与使用

1. 在「AI 助理」配置聊天分析模型，在「ComfyUI 与工作流」配置服务并导入 API 工作流。将 `%prompt%` 放在工作流接收提示词的位置。
2. 在「模型与偏好」选择图像模型，复制「小猫指令」到预设、角色卡或世界书。
3. 手动模式可从图卡生成图片。自动模式只排最新 AI 楼层的新图位。使用「重新解析」可按当前模型重写单张图的提示词。在主面板的「一键排图」下方输入楼层（如 `56,58-60,62`），点击「手动排图」可补解析这些楼层并排队生成缺少的图片。
4. 在「角色档案」编辑英文锚点或删除单个人物。当前聊天置顶并默认展开。「其他」按聊天标题倒序排列，可打开另一场聊天，或将其中缺少的人物复制到当前聊天。
5. 在「图库」展开「其他」，选择另一个聊天的「使用此图库缓存」。仅复用所选图库中同模型、同占位符内容的已生成图片。复用结果计入当前聊天。

工作流原文透传。发送时替换 `%prompt%`，采样器的数值零种子会随机化。MiniMax-H3-Image 模式按纯二维视觉小说事件 CG 编写提示词，实际 16:9 画布由工作流设置。

## 2.0.0 存档变更

人物档案、造型、图库及图卡缓存以角色卡文件名和完整聊天文件名识别。存档写入酒馆用户目录 `user/files/cat-image-v2-a.json.gz` 与 `user/files/cat-image-v2-b.json.gz`，两份文件轮换写入。偏好由酒馆在 `extension_settings.cat_image` 中保存。

**这是存档格式变更。** 旧版资料需要离线迁移到新格式。升级前备份酒馆设置、WebView 存储和本地图片。历史归档仍可浏览，确认来源后可手动复制人物。

更详细的操作见 [使用指南](GUIDE.md)。开发验证见 [测试说明](TESTING.md)。
